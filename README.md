# Blog — Учебный веб-проект на Django

Веб-приложение блога с публичной лентой публикаций, регистрацией и авторизацией пользователей, а также разграничением прав на создание и редактирование записей.

## Функциональность
- Публичный просмотр всех публикаций в обратном хронологическом порядке.
- Регистрация новых пользователей, вход и выход из аккаунта (строго через POST-запрос).
- Создание новых публикаций с автоматической привязкой к текущему автору (`owner`).
- Редактирование публикаций доступно только их автору.
- Адаптивный интерфейс на базе `django-bootstrap4`.

## Запуск локально
```bash
python3 -m venv ll_env
source ll_env/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

## Запуск в Docker
```bash
cp .env.example .env
docker compose up -d --build
```
